# SHRIDHAR D — Portfolio (Static)

This is a clean, responsive single-page portfolio built from the provided resume content.

To view locally:

1. Open `index.html` in a browser (double-click or use a local server).

Optional: serve with a local server for correct routing:

```bash
# Python 3
python -m http.server 8000
# then open http://localhost:8000
```

Files added:
- `index.html` — main markup
- `styles.css` — responsive styling
- `script.js` — small interactive behaviors

Notes:
- Profile photo, GitHub link and resume PDF are left as placeholders per the resume.
- All content is taken from the supplied resume; nothing was invented.
